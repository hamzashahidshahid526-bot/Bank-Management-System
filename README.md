# Bank-Management-System
This is my project Bank Management System. I used C++ core fundamentals and Object Oriented Programming roots to complete this
# Features
1:-Create Account
2:-Create SavingsAccount
3:-Create CheckingAccount
4:-Display All Accounts
5:-Deposit Money
6:-Withdraw Money
7:-Show Transaction History
8:-Find An Account
9:-Exit
# How to use ?
You Will be given a menu . Chose one of the 9 provided options.
I have also provided .txt files from which you can see your transaction history has been saved permanently .
Additionally i also attached a .csv file at the end in which you can see your transaction history in MS Excel
