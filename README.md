# Bank-Management-System
This is my project Bank Management System. I used C++ core fundamentals and Object Oriented Programming roots to complete this
# Features
1:-Create Account<br>
2:-Create SavingsAccount<br>
3:-Create CheckingAccount<br>
4:-Display All Accounts<br>
5:-Deposit Money<br>
6:-Withdraw Money<br>
7:-Show Transaction History<br>
8:-Find An Account<br>
9:-Exit<br>
# How to use ?<br>
You Will be given a menu . Chose one of the 9 provided options.<br>
I have also provided .txt files from which you can see your transaction history has been saved permanently .<br>
Additionally i also attached a .csv file at the end in which you can see your transaction history in MS Excel
